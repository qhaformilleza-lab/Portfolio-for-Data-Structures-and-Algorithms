Course Description.

This course focuses on solving computational problems that manipulate collected data, data structures, and algorithms that provides a foundation for writing efficient programs. The course content includes topics in Dynamic memory allocation, Linked lists, along with abstract data types, including graphs, trees, heaps, stacks, and queues. The course introduced topics related to linear and binary searches as well as different types and implementations of sorting algorithms. The student's outcome is to design algorithms for each data structures with different implementations and to use data structures and algorithms in the design of an effective program that will solve an engineering-related problem using C++.

This is a compilation of all the hands on activity in this course
